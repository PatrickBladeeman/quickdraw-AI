documents by responsibility. This compatibility file exists for older links;
it is not an independent source of project truth and is not synchronized
field-for-field with the ignored local `CONTEXT.md`.

## Compatibility rule

Do not add duplicated current state, research values, milestone results, or
procedural instructions here. Update the owning document and keep only the
appropriate link in this index.

Local/private material remains in ignored local context files and must not be
copied here.
